# keys/

Credentials for your own Salesforce Developer Edition org.

`consumer_key` and `consumer_secret` come from Setup, under
**External Client App Manager -> your app -> Settings -> OAuth Settings**.

| File | Written by |
|---|---|
| `consumer_key` | you |
| `consumer_secret` | you |
| `access_token` | `02_exchange_code.sh`, `03_refresh_access_token.sh` |
| `refresh_token` | `02_exchange_code.sh` |
| `instance_url` | `02_exchange_code.sh`, `03_refresh_access_token.sh` |
